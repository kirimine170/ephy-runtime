# チャット回答の読み上げ

チャットから送った回答も，「声と話し方」で選択した声と設定で読み上げる．「チャットの回答を読み上げる」は初期状態でONで，OFFの選択は次回起動時も維持する．声そのものの保存方針は既存の設定に従う．

文字入力ではマイク，ASR，フィラー用の割込み検出を開始しない．モード，履歴，参照範囲，Web検索の設定と通常チャットの出力上限を引き継ぎ，一つの生成結果を画面表示と読み上げに使用する．Thinkingと参照元は画面に表示し，読み上げと会話記録には混ぜない．

「応答を停止」で生成と再生を停止できる．生成済みの回答は，その後に再生を止めても次のチャットの履歴に残る．音声合成が失敗した場合は文字の回答を最後まで生成し，読み上げ失敗を表示する．記録ONの場合，確定入力と回答をそれぞれ一度だけ記録し，音声の再生結果を別に保持する．

Deep Workの長い推論を途中で打ち切っていたRuntimeとHTTPクライアントの90秒制限は，生成用の有限な10分上限へ変更した．停止操作は引き続き即時キャンセルする．制御用HTTPリクエストの上限は変えない．モデルの推論量と出力トークン上限も変えない．

連続音声会話では，ASR確定時の未送信音声の検査対象を，その入力の開始時に引き継いだ音声に限定した．確定中に始まった次の発話の候補を，直前の入力のプロトコル違反と誤認しない．

検証は，音声合成成功／失敗と確定記録，文字入力時のマイク非使用，再生と停止，送信前キャンセル，早い完了通知，Thinkingと参照元の分離，履歴の継続，設定の保存，長い生成とキャンセル，ASR確定中の次発話を対象とする．実機の結果は作業ログに記録する．
